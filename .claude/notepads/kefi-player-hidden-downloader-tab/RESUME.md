## The one rule that cost the most to learn

**Only the orchestrator runs `npm run qa`, serialized, with no agent working.** There is one
emulator. Parallel agents each running the suite produced 30/38, 29/38, 23/38, 31/38, 16/34,
27/37, 22/38 — pure contention, not regressions. A pass reported by an agent that ran
concurrently with another agent is not evidence and must be re-run. The clean serialized gate
at this checkpoint is **38/38**. Every delegation prompt must forbid `npm run qa` explicitly.
